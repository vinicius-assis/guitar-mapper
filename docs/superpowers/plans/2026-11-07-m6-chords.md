# M6 Acordes Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trilha nova "Acordes" (só violão) com dois exercícios — "Nome do acorde" (ver o desenho no braço e escolher o nome entre 4) e "Monte o acorde" (tocar as casas presas do desenho pedido) — sobre uma tabela curada de 19 desenhos abertos e 10 de pestana, com nomes grafados pelo ajuste Acidentais e revisão espaçada por item.

**Architecture:** Um módulo puro `src/domain/chords.ts` define qualidades, grafia do acorde (regra do `spellScale` aplicada ao acorde), a tabela de desenhos e `chordVoicing` (posições, alturas, funções, ○/×, pestana, janela). `src/domain/chordItems.ts` define itens, chaves, pools e filas (com as 4 opções do Nome do acorde); `storage.ts` aceita ajustes e chaves novos de forma aditiva. O `Fretboard` ganha só peças opcionais (marca `chord`, coluna ○/×, pestana); duas telas novas usam `src/ui/chordText.ts`, e o registro liga tudo numa trilha nova com bloqueio no baixo.

**Tech Stack:** React 19, TypeScript, Vite, Vitest + Testing Library (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-07-m6-chords-design.md`
