> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trilha nova "Escalas" com dois exercícios ("Grau no desenho" e "Toque a escala") sobre 10 escalas (pentatônicas, blues, maior, menor natural e 5 modos), com desenhos corretos no violão e no baixo, grafia uma-letra-por-grau e revisão espaçada por item.

**Architecture:** Um módulo puro novo, `src/domain/scales.ts`, define as escalas, os graus e a geometria dos desenhos (regra única de 2 ou 3 notas por corda, mais a ♭5 do blues). `spelling.ts` ganha `spellScale`. Um segundo módulo puro, `src/domain/scaleItems.ts`, define itens, chaves, pools e filas dos dois exercícios; `storage.ts` aceita os ajustes e chaves novos de forma aditiva. Duas telas novas usam o `Fretboard` com as marcas novas `root`/`scale`, e o registro liga tudo numa trilha nova.

**Tech Stack:** React 19, TypeScript, Vite, Vitest + Testing Library (jsdom).

**Spec:** `docs/superpowers/specs/2026-11-07-m4-scales-design.md`

**Interfaces:**

- Produces (Tasks 2–5):
  - `type ScaleId = 'pent-minor' | 'pent-major' | 'blues' | 'major' | 'minor' | 'dorian' | 'phrygian' | 'lydian' | 'mixolydian' | 'locrian'`; `SCALE_IDS: readonly ScaleId[]`; `isScaleId(value: unknown): value is ScaleId`
  - `interface ScaleDef { id: ScaleId; label: string; name: string; semitones: readonly number[]; letterSteps: readonly number[]; degrees: readonly string[]; notesPerString: 2 | 3; base?: 'pent-minor'; blueNote?: number; boxCount: number }`
  - `SCALES: Record<ScaleId, ScaleDef>`
  - `SCALE_GROUPS: readonly { label: string; scales: readonly ScaleId[] }[]` = `'Pentatônicas e blues'` [pent-minor, pent-major, blues], `'Maior e menor'` [major, minor], `'Modos'` [dorian, phrygian, lydian, mixolydian, locrian]
  - `interface BoxNote { position: Position; pitch: number; degree: number }` (`degree` = índice em `semitones`, 0 = tônica)
  - `interface ScaleBox { notes: BoxNote[]; fretMin: number; fretMax: number }`
  - `scaleBox(scale: ScaleId, box: number, root: NoteIndex, instrument: Instrument): ScaleBox` — `notes` ordenadas por corda decrescente e casa crescente
  - `scaleDegreeOf(pitchClass: NoteIndex, root: NoteIndex, scale: ScaleId): number` (índice ou `-1`)

Valores (`label` / `name` / `semitones` / `letterSteps` / `degrees` exatamente como a tabela da spec, seção 2). `notesPerString`: 2 nas pentatônicas e no blues, 3 nas de 7 notas. `blues`: `base: 'pent-minor'`, `blueNote: 3`, `boxCount: 5`; demais `boxCount = semitones.length`. `degrees` pode ser escrito à mão ou derivado; o teste fixa os valores.

Algoritmo do desenho (o que o teste não determina sozinho):

```ts
// Sem `base`: N = stringCount, low = openMidi[N - 1], n = semitones.length.
// start = menor altura >= low com classe (root + semitones[box - 1]) % 12, e base = start - semitones[box - 1].
// Para idx = box-1 .. box-1 + N*notesPerString - 1, corda de N até 1 (notesPerString notas por corda):
//   pitch = base + semitones[idx % n] + 12 * Math.floor(idx / n); fret = pitch - openMidi[corda - 1]; degree = idx % n
// Enquanto alguma casa < FIRST_QUIZ_FRET: some 12 a tudo.
// Com `base` (blues): pega scaleBox('pent-minor', box, root, inst); mapeia degree pelo índice [0,1,2,4,5];
// acrescenta toda posição (qualquer corda, casa em fretMin..fretMax) com classe (root + 6) % 12 e altura ainda
// ausente, degree 3; reordena.
```

### Task 2: Grafia de escala (`spellScale`)

**Files:**
- Modify: `src/domain/spelling.ts`
- Create: `src/domain/scaleSpelling.test.ts`

**Interfaces:**
- Consumes: `ScaleDef`, `SCALES`, `SCALE_IDS`, `ScaleId` (Task 1). Em `spelling.ts`, só `import type { ScaleDef } from './scales'` (evita o ciclo `notes → spelling → scales → fretboard → notes`).
- Produces (Tasks 4–5): `spellScale(root: NoteIndex, scale: ScaleDef, accidentals: Accidentals): Spelling[]` (um por grau, na ordem de `semitones`).

Regras:
- Grafia a partir de um nome de tônica: letra do grau *i* = `LETTERS[(letra da tônica + letterSteps[i]) % 7]`; sinal = classe − natural da letra, normalizado para −6..6. Se `i === scale.blueNote` e o sinal < −1, usa a letra `(letra da tônica + 3) % 7` (a da 4ª).
- Válida = todo sinal em −1..1.
- Candidatos: tônica natural → só a natural. Tônica preta → `sharp`: [sustenido, bemol]; `flat`: [bemol, sustenido]; `auto`: os dois, o de menor soma de |sinal| entre os válidos primeiro, empate → o de `TABLES.auto`. Devolve o primeiro válido. (Sempre existe um; o teste garante.)
- `spellNote`, `spellInterval` e `spellingLabel` não mudam.
